O **GoalConnect** é um aplicativo móvel desenvolvido para a plataforma Android que ajuda torcedores locais e internacionais a se localizarem e se conectarem durante o período da Copa do Mundo de 2026. A aplicação mapeia e anuncia os principais pontos de concentração de torcidas, como bares, restaurantes, praças e fan zones.

> 🎓 **Projeto Acadêmico** desenvolvido para o curso de Análise e Desenvolvimento de Sistemas (ADS).

---

## 🎯 Proposta de Valor

Durante grandes eventos esportivos, encontrar o lugar ideal para assistir aos jogos com a torcida certa pode ser um desafio para quem é de fora. O GoalConnect resolve isso centralizando a agenda de eventos, a localização de estabelecimentos parceiros e o "termômetro" de torcedores por região em tempo real.

---

## 🛠️ Tecnologias Utilizadas

- **Framework:** [React Native](https://reactnative.dev/)
- **Plataforma:** [Expo](https://expo.dev/) (Managed Workflow)
- **Mapas e Geolocalização:** Expo Location / React Native Maps
- **Estilização:** Tailwind CSS (NativeWind)
- **Consumo de Dados:** Axios / Fetch API

---

## ✨ Funcionalidades Principais

- [ ] **Mapa Interativo (Fan Map):** Visualização de estabelecimentos, praças e locais de exibição dos jogos com filtros por proximidade.
- [ ] **Filtro de Torcidas:** Descubra onde a torcida de um país específico está se concentrando para um determinado jogo.
- [ ] **Eventos em Destaque:** Lista de bares e restaurantes parceiros com programações especiais, promoções e horários de transmissão.
- [ ] **Check-in de Presença:** Permite que o usuário indique em qual local vai assistir à partida, ajudando a calcular a lotação estimada em tempo real.
- [ ] **Suporte Multi-idioma:** Interface adaptada para receber turistas internacionais de forma intuitiva.

## 📲 Como Rodar a Aplicação

### Pré-requisitos

1. Certifique-se de ter o **Node.js** instalado na sua máquina de desenvolvimento.
2. Instale o aplicativo **Expo Go** no seu dispositivo Android através da Google Play Store.

### Passo a Passo

```bash
# 1. Clone o repositório
$ git clone [https://github.com/seu-usuario/goalconnect-app.git](https://github.com/seu-usuario/goalconnect-app.git)

# 2. Acesse o diretório do projeto
$ cd goalconnect-app

# 3. Instale todas as dependências necessárias
$ npm install

# 4. Inicie o servidor de desenvolvimento do Expo
$ npx expo start
```
